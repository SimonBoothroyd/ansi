the macro line appends · 2 fibre on a row that states one, and prints nothing at all on a row that does not — fibre is the one optional figure, and its absence is an absence, never a zero. It is spelled out because F is already fat

the picker’s rows carry no source line. The manager and the import review both name the food behind a filled row (the USDA description, or the pack a barcode was scanned off); this one deliberately does not — it is a search surface, and a description under every row is noise while you are typing
